How It Works:

Parse Results  →  Compute KPIs  →  Detect Anomalies  →  Query Observability  →  Verdict
 (k6, JMeter,     (P50-P99,        (z-score, MAD,       (Prometheus,           APPROVE
  Gatling,          throughput,       trend analysis)       Loki, Tempo)          or
  Locust, HAR)      error rate)                                                 REJECT

The agent dynamically decides which tools to call, correlates signals, and produces a traceable deployment decision.

Three Ways to Use Heimr:

Agent Mode

heimr agent results.json \
  --gate-policy strict \
  --fail-condition "p99 > 500"

Autonomous deployment gating with verdict + audit trail.

MCP Server

claude mcp add heimr-perf \
  -- python -m \
  heimr.agent.mcp_server

Use Heimr tools directly from Claude Code or Claude Desktop.

Detailed Reports

heimr analyze results.json \
  --output report.html \
  --prometheus prom:9090

Interactive HTML/PDF reports with charts and AI root cause analysis.
