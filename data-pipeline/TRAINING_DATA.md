# 🧠 Training Data Documentation

## Dataset Overview

The training dataset is generated by the **Data Pipeline** and stored in Parquet format. It contains multi-modal data (metrics, logs, traces) labeled with chaos scenarios.

**Location**: `data-pipeline/datasets/processed/training_data.parquet`

---

## 📊 Data Schema

Each row in the dataset represents a **1-minute time window** of system behavior.

### 1. Features (Input)

| Feature Group | Description | Source |
|---------------|-------------|--------|
| **Application Metrics** | Request rates, latency (p50, p95, p99), error rates | Prometheus |
| **System Metrics** | CPU usage, memory usage, network I/O | Prometheus |
| **GPU Metrics** | Utilization, temperature, power draw, memory usage | DCGM / NVIDIA SMI |
| **Log Patterns** | Error log counts, exception types, log volume | Loki |
| **Trace Patterns** | Average span duration, error span counts | Tempo |

### 2. Labels (Output)

| Label | Description | Example |
|-------|-------------|---------|
| `bottleneck_type` | The type of performance issue | `cpu_saturation`, `gpu_memory_leak` |
| `severity` | Impact level (0.0 - 1.0) | `0.8` (High) |
| `root_cause` | Text description of the cause | "High CPU usage due to matrix multiplication" |
| `fix_recommendation` | Suggested remediation | "Scale up replicas or optimize code" |

---

## 🧪 Scenarios

The dataset includes examples from 10 different chaos scenarios:

1. **Healthy**: Baseline behavior
2. **CPU Spike**: High CPU usage
3. **Memory Leak**: Gradual memory increase
4. **Disk I/O Latency**: Slow disk operations
5. **Network Latency**: Added network delay
6. **Packet Loss**: Dropped network packets
7. **Exception Spike**: High application error rate
8. **Database Connection Limit**: Connection pool exhaustion
9. **GPU Saturation**: High GPU compute load
10. **GPU Memory Leak**: High GPU memory usage

## 🚀 How to Use

### Loading the Data (Python)

```python
import pandas as pd

# Load the dataset
df = pd.read_parquet('data-pipeline/datasets/processed/training_data.parquet')

# Inspect features
print(df.head())

# Check label distribution
print(df['labels.bottleneck_type'].value_counts())
```

### Training a Model

```python
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier

# Prepare features and labels
X = df.drop(columns=['labels.bottleneck_type', 'labels.root_cause', ...])
y = df['labels.bottleneck_type']

# Split data
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# Train model
clf = RandomForestClassifier()
clf.fit(X_train, y_train)

# Evaluate
print(clf.score(X_test, y_test))
```
